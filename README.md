# Feira USP e as Profissões 2026

Repositório com projetos para serem apresentados na Feira USP e as Profissões 2026.

## Estrutura

- **ia/** --- projetos de machine learning (reconhecimento de gestos com MediaPipe e análise facial com DeepFace).
- **teoria/** --- animações interativas de teoria dos grafos (Dijkstra e Teorema das 4 Cores).
- **termo/** --- jogo Termo (Wordle) em Python.
- **docs/** --- apresentações
  
Cada subpasta com `requirements.txt` tem suas próprias dependências: 

```bash
pip install -r <pasta>/requirements.txt
```
